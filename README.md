# NEXA — Landing Page

Landing page conceitual SaaS para portfólio.

## Stack
HTML5 + CSS3 + JavaScript puro.

## Direção visual
- Fundo escuro atual preservado.
- Grid sutil.
- Glow roxo/azul.
- Estética SaaS premium e tecnológica.
- Não substituir a identidade visual sem necessidade.

## Estado
Blocos concluídos:
01 — Estrutura
02 — Background
03 — Navbar
04 — Hero

Próximo:
05 — Dashboard.

## Regra de design
Construir incrementalmente. Não refazer blocos já aprovados.
Na etapa final, revisar bordas, radius, sombras, cards, espaçamentos e detalhes para evitar aparência genérica de site gerado por IA.
